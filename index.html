Task Management

Create Tasks That Actually Get Done.

Legal follow-ups get lost when they're not captured immediately. Mattermail lets you create a fully-detailed Clio task the moment you read an email while the context is still fresh.

  • Task name auto-fills from the email subject line
  • Set priority: Normal, High, or Low visible in Clio immediately
  • Assign to any user in your Clio account from a dropdown
  • Choose a task type from your firm's configured Clio categories
  • Set a due date and time estimate in hours
  • One-click templates: Call client, Save attachments, Review & draft response
  • Task description auto-fills with sender name for context

Time Tracking

Log Time the Moment It Happens.

  • Natural duration input: 1h 30m, 1:30, or decimal hours
  • Free-text description field for activity notes
  • Custom hourly rate per entry for accurate billing
  • Time entries are linked to the selected matter in Clio
  • Works alongside email filing log time and save email in one action

What Mattermail Does

Every Tool Your Practice
Needs, Inside Gmail.

Legal work lives in your inbox. Mattermail brings Clio's core capabilities directly into Gmail so nothing falls through the cracks.

File Emails to Matters

Select any email or entire thread and save it directly to an open matter in Clio. Choose between threading all emails into a single communication or filing each message individually for granular record-keeping.

Thread mode Individual mode 200+ matters

Attachment Management

All attachments across the thread are detected automatically. Use bulk select or deselect individual files to precisely control what gets uploaded to your matter in Clio no manual downloading required.

Auto-detect Bulk select PDF & DOCX

Time Entry Logging

Log time without leaving the email. Enter duration in natural format (e.g. 1h 30m or 1:30), add a description, and set your hourly rate all synced directly to Clio's time entries for the selected matter.

Flexible duration input Custom rate Direct Clio sync

Task Creation

Create Clio tasks directly from any email. Set the task name, description, priority level, assignee, due date, and time estimate all without switching to Clio. Pre-built templates make common actions instant.

Priority levels Due date picker Assignee dropdown

Quick Task Templates

One-click templates auto-populate task fields for the most common legal follow-up actions. Stop typing the same task names for every client email.

Smart Matter Dropdown

All open matters are fetched from Clio and cached for instant loading. The add-on remembers your last selected matter to speed up repeat filings on the same case. One refresh syncs new matters immediately.

Simple by Design

Three Steps to a Filed Email.

01
Connect Clio Once

Authorize Mattermail to access your Clio account via secure OAuth. Your credentials are never stored authentication is handled entirely by Clio's own authorization servers.

02
Open Any Email Thread

Click Mattermail in the Gmail sidebar. Select which emails and attachments to file, pick your matter from the dropdown, and choose whether to save as a thread or individually.

03
Log, Track & Move On

Hit Save to Clio. Optionally log time and create follow-up tasks in the same action. Every detail lands in Clio instantly no copy-pasting, no tab switching, no delays.
