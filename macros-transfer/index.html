From VBA to Apps Script

A simplified example of the kind of translation you can expect.

EXCEL VBA
Private Sub Worksheet_Change(ByVal Target As Range)
  If Target.Column = 2 Then
    Target.Offset(0, 1).Value = Now
  End If
End Sub
GOOGLE APPS SCRIPT
function onEdit(e) {
  const r = e.range;
  if (r.getColumn() === 2) {
    r.offset(0, 1).setValue(new Date());
  }
}

Know what to expect

Not every VBA feature exists in the cloud. We tell you up front.

Usually converts well

  • Cell and range reads and writes
  • Loops, conditions, and custom functions
  • Sheet edit and open events
  • Formatting and basic data processing

Needs manual attention

  • Buttons lose their script assignments and must be reassigned
  • Windows APIs, COM objects, and ActiveX controls
  • Local file system and desktop app automation
  • Always review and test AI-generated code before use

Frequently asked questions

Which file types are supported?

You can upload .xlsm, .xls, .xlsb, and .xltm files up to 25 MB each, or paste VBA code directly.

Will my converted macros work perfectly?

Often they work with little editing, but conversion is done by AI and some VBA features have no Google Apps Script equivalent. The compatibility report highlights what needs manual changes. Review and test the code before relying on it.

Where do my files go?

The converted spreadsheet is created in your own Google Drive. Your workbook is processed to extract macro code, and the VBA code is sent to an AI service for conversion. Read the Privacy Policy for the full details.

Why do I have to authorize the add-on?

It needs permission to create the converted spreadsheet and script in your Drive and to show the sidebar in Google Sheets. It only accesses files it creates or that you open with it.

My buttons stopped working. Why?

Excel button assignments cannot carry over. In Google Sheets, right-click the button, choose Assign script, and enter the function name from the converted code.

Is it free?

A free plan is available. Plans and limits may change over time.

How do I report a bug or give feedback?

Use the "Feedback & Bugs" link at the bottom of the sidebar, or the link in the footer of this page.
